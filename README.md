# Novelon Extensions

Extensions (extra novel sources) for [Novelon](https://github.com/Dextonek/novelon), a novel reader for Android.

## Adding the repository

In Novelon, open **Settings → Browse → Extension repos** and add:

```
https://raw.githubusercontent.com/Dextonek/novelon-extensions/main/index.min.json
```

The extensions then appear under **Browse → Extensions**, ready to install and update.

## Extensions

| Extension | Site |
| --- | --- |
| Royal Road | https://www.royalroad.com |
| Scribble Hub | https://www.scribblehub.com |

This repository holds only the built extensions and their index. Every APK is signed with the key whose SHA-256
fingerprint is in `repo.json`.

## Disclaimer

The extensions only read pages that the sites themselves serve publicly. This repository hosts no content, and its
developers have no affiliation with the sites.
